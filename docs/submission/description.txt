Prompt2Prod is an autonomous AI dev crew. A developer types or speaks a change (or sends it via CLI/REST webhook) and five Gemini agents built with Google ADK ship it end-to-end: plan, write failing tests first, code with sandboxed tools, self-heal failures, AI code review, build, deploy a live preview, verify it with AI smoke tests and multimodal visual QA, then release on Autopilot or after one-click approval, with instant rollback. Measured on 9 real runs: ~2.5 min prompt to production, ~$0.15 per change.
Gemini: 3.1 Pro (planner, reviewer) + 3.6 Flash (tests, coder, verifier) on Vertex AI.
Cloud Run: API + dashboard, an isolated Cloud Run Job per request, and every change as a tagged preview revision; release/rollback = traffic switch. Cloud Build + Artifact Registry build images.
Firestore: tasks, live agent event stream, releases, locks.
Firebase: Auth, Hosting (prompt2prod.web.app) and realtime listeners streaming every agent step to the dashboard.
